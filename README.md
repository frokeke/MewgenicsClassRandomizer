# MewgenicsClassRandomizer

## Como compilar o código?

Para compilar este código, por conta de utilizar apenas referências nativas da linguagem C++, você precisará apenas ter instalado algum compilador de código como o MinGW ou o MSVC.

Com este compilador instalado, execute o seguinte comando no cmd:

`g++ MewgenicsClassRando.cpp -o MewgenicsClassRando.exe`
Pelo MinGW

`cl /EHsc MewgenicsClassRando.cpp`
Pelo MSVC


### Notação Importante: Abra o arquivo .sav utilizando o VSCode ou algum outro IDE para facilitar visualização.
